# Configuring a request

While you can send a basic HTTP request just using the verb and the method,
you probably want to configure some data about your HTTP request. The
tabs in the request pane can help with that.

There are currently five tabs in this pane:

* [Parameters](request/parameters.md): used to handle the query parameters
  of the HTTP request in use.
* [Headers](request/headers.md): used to inspect or change the request headers.
* [Variables](request/variables.md): used to inspect, set or delete variables
  and check the status of the dot-env files.
* [Authorization](request/authorization.md): Cartero can help you configure
  the authentication and authorization credentials of your HTTP request.
* [Body](request/body.md): Set the request body of your HTTP request.

In previous versions of Cartero, there was a tab called "Export request". The
functionalities provided by this tab are now present in the "Export menu".
Check out the [Export menu](export.md) chapter for more information on how
to use this menu.

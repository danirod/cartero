# Advanced usage

These are some advanced patterns and flow for power users:

* [Using .env files](./advanced/env.md): if you manage multiple request files
  or you have sensitive files that you'd rather keep out the .cartero files,
  you can use this.

* [Export menu](./advanced/export.md): use the Export menu to send the request
  or the response to a different format that can be exchanged with a different
  program or shared.
